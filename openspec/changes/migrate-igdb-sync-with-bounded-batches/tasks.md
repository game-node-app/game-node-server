# Tasks

Implement in numbered order. All boxes are implementation work, not work performed while writing this plan. Proposed new importer files live under `src/sync/igdb/catalog/` (abbreviated `catalog/` below). Existing files are named explicitly. Defaults and bounds are fixed in design decision 7; do not invent different values. Keep the legacy processor and unrelated queues working.

All verification is local. Use a stub IGDB source and isolated disposable MySQL/Redis. Do not provision or access a VPS, request production credentials, run a live catalog import, modify existing deployment Compose files, or defer completion to future infrastructure availability.
