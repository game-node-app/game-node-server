## Gaps

1. Source object never stored — no object-storage assertion; code inspection only.
2. Other slot while one is processing — claim query scoped per slot, not executed.
3. Malicious file name — generated paths only, inspected, not tested.
4. Subscription returns — stateless read inspected, not tested with entitlement toggled back.
5. Static banner over a video banner — avatar path executed; banner branch not.
6. Existing GIF avatar — no read-time format logic, inspected only.
7. GIF in a post — no dedicated post test; unchanged `UploadService.save` regression test only.

Also not executed end-to-end: a real conversion above a size budget (only the boundary guard), the
full 180 s kill, object-storage upload/delete, and duration/CPU measurement on the production CPU
profile. Task 8.2 (real phone samples, browser playback, production proxy) remains with the owner.
